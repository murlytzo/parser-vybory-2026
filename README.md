# 🗳️ Парсер данных Избиркома

Скрипт собирает детальную электоральную статистику по каждому участку (УИК) избирательного округа с сайта [izbirkom.ru](http://izbirkom.ru) и сохраняет её в одну плоскую таблицу: CSV-файл и, по желанию, Google Таблицу.

Одна строка таблицы — один УИК. В колонках:

- **открытие помещений для голосования** — число избирателей в списках, приступили ли к работе;
- **явка по дням** — число проголосовавших и процент на каждое отчётное время за все дни голосования;
- **заявления «Мобильного избирателя»** — сколько избирателей включено в список по месту нахождения и сколько исключено из списка по месту жительства (отдельно по заявлениям о голосовании по месту нахождения и ДЭГ);
- **результаты голосования** — строки протокола (бюллетени) и голоса за каждую партию и каждого кандидата, число и процент, отдельно по федеральному и одномандатному округу. Каждый протокол проверяется по контрольным соотношениям.

Списки партий и кандидатов вводить не нужно: названия колонок скрипт берёт прямо из таблиц на сайте, поэтому он подходит для любого округа.

## Как это работает

Данные на сайте Избиркома устроены иерархически: **ОИК** (округ) → **ТИК** (территориальные комиссии) → **УИК** (участки).

1. Скрипт открывает страницу вашего округа и находит в отчёте о явке список всех ТИКов.
2. Для каждого ТИКа открываются отчёты об открытии помещений и о явке. В них все УИКи ТИКа идут строками одной таблицы, поэтому одна страница даёт данные сразу по всем участкам. Отсюда же скрипт берёт ссылки на страницы самих УИКов.
3. Для каждого УИКа открываются страницы результатов и заявлений: эти данные публикуются только на уровне участка.

Сайт Избиркома — это динамическое веб-приложение (Vue.js) с защитой от ботов, поэтому скрипт управляет настоящим браузером Chrome через [undetected-chromedriver](https://github.com/ultrafunkamsterdam/undetected-chromedriver). Он переходит между страницами так же, как человек кликает по ссылкам, делает случайные паузы, а если страница не загрузилась, возвращается на главную и пробует снова. Если появится капча, скрипт встанет на паузу и попросит решить её вручную.

Прогресс сохраняется после каждой загруженной страницы, так что сбор можно прервать и продолжить в любой момент.

## Что понадобится

- **Python 3.9 или новее** — [python.org/downloads](https://www.python.org/downloads/). При установке на Windows обязательно отметьте галочку **«Add Python to PATH»**.
- **Google Chrome** — обычный, установленный на компьютер.
- **Доступ к izbirkom.ru.** Сайт часто не открывается с зарубежных IP-адресов. Если он не открывается у вас в обычном браузере, скрипт тоже не сможет его открыть — см. [Частые проблемы](#частые-проблемы).
- **Google-аккаунт** — только если хотите выгружать данные в Google Таблицу. Без него результат сохранится в CSV-файл.

## Установка

### 1. Скачайте проект

Нажмите на GitHub зелёную кнопку **Code → Download ZIP** и распакуйте архив в любую папку. Или, если у вас есть git:

```bash
git clone https://github.com/murlytzo/parser-vybory-2026.git
```

### 2. Установите библиотеки

Откройте терминал в папке проекта. На Windows: откройте папку в Проводнике, нажмите на адресную строку, введите `cmd` и нажмите Enter. Выполните:

```bash
pip install -r requirements.txt
```

Если команда `pip` не найдена, попробуйте:

```bash
python -m pip install -r requirements.txt
```

или на Windows:

```bash
py -m pip install -r requirements.txt
```

## Настройка

### 3. Файл настроек `config.json`

Скопируйте файл `config.example.json` и назовите копию `config.json`. Откройте её в любом текстовом редакторе (например, в Блокноте):

```json
{
  "start_url": "http://izbirkom.ru/election/587813923/commission/e6119ea7-30d5-4917-863e-428913c947ef/",
  "google_sheet_url": "",
  "tik_urls": {},
  "chrome_version": null,
  "wait_for_results": false
}
```

| Параметр | Что это |
|---|---|
| `start_url` | **Обязательно.** Ссылка на страницу вашего округа (ОИК), см. ниже, как её найти. |
| `google_sheet_url` | Ссылка на Google Таблицу. Оставьте `""`, если нужен только CSV. |
| `tik_urls` | Запасной вариант, если скрипт не найдёт ТИКи сам. Обычно оставьте `{}`. |
| `chrome_version` | Номер версии Chrome, только если возникнет ошибка версии. Обычно оставьте `null`. |
| `wait_for_results` | `true` — включить [режим ожидания](#режим-ожидания-можно-оставить-на-ночь). |

**Как найти `start_url`:**

1. Откройте [izbirkom.ru](http://izbirkom.ru) → «Календарь выборов» → нужные выборы.
2. Нажмите на строку с цепочкой комиссий («ЦИК России » …) и в открывшемся дереве выберите ваш регион, а в нём — ваш округ (метка **ОИК**).
3. Скопируйте ссылку из адресной строки. Она должна выглядеть так:
   `http://izbirkom.ru/election/<номер выборов>/commission/<идентификатор>/?tab=info`
   Часть `?tab=info` в конце можно оставить или убрать.

> ⚠️ `config.json` указан в `.gitignore` и не попадёт в репозиторий, если вы будете публиковать свою копию проекта.

### 4. Google Таблица (необязательно)

Пропустите этот шаг, если вам достаточно CSV-файла.

Скрипту нужен «сервисный аккаунт» — технический Google-аккаунт с ключом, от имени которого он будет писать в таблицу.

1. Откройте [Google Cloud Console](https://console.cloud.google.com/) и создайте новый проект (выпадающее меню вверху → **New Project**).
2. Через поиск вверху найдите **Google Sheets API** и нажмите **Enable** (Включить). Так же включите **Google Drive API**.
3. Перейдите в **APIs & Services → Credentials → + Create Credentials → Service account**. Придумайте любое имя и нажмите **Done**.
4. Нажмите на созданный аккаунт → вкладка **Keys** → **Add Key → Create new key → JSON**. Скачается файл с ключом.
5. Переименуйте его в **`credentials.json`** и положите в папку проекта.
6. Скопируйте email сервисного аккаунта (заканчивается на `...iam.gserviceaccount.com`, виден в списке Credentials).
7. Создайте пустую Google Таблицу, нажмите **«Настройки доступа»** и добавьте этот email с правами **Редактор**.
8. Скопируйте ссылку на таблицу из адресной строки и вставьте её в `config.json` в поле `google_sheet_url`.

> ⚠️ **`credentials.json` — это ключ доступа.** Никогда не публикуйте его и никому не отправляйте. Он тоже указан в `.gitignore`.

> ℹ️ Скрипт каждый раз **полностью перезаписывает первый лист** таблицы. Используйте отдельную таблицу или держите свои заметки на других листах.

## Запуск

Откройте терминал в папке проекта и выполните:

```bash
python parser.py
```

(или `py parser.py` на Windows, если команда `python` не распознаётся).

Откроется окно Chrome — **не закрывайте и не сворачивайте его**, скрипт работает через него. В терминале будет виден ход работы:

```
=== ТИК 1/11: Алексеевская ===
  • Открытие
    УИКов в отчёте: 25
  • Явка Д1
  ...
  [3/25] УИК №103 — Фед
    Показателей: 27
  💾 Сохранено: 25 УИК, 142 колонок (results.csv + Google Таблица)
  ⏱ Осталось примерно: 1:12:40
```

Данные сохраняются после каждого ТИКа, так что открывать таблицу можно, не дожидаясь конца сбора.

### Если появилась капча

Скрипт остановится и напишет в терминале **«СРАБОТАЛА ЗАЩИТА (КАПЧА)»**. Решите капчу в окне Chrome, вернитесь в терминал и нажмите **Enter** — сбор продолжится.

### Режим ожидания (можно оставить на ночь)

Избирком иногда убирает результаты с сайта на несколько часов, а потом возвращает. Чтобы не караулить этот момент, включите режим ожидания: `"wait_for_results": true` в `config.json` или флаг при запуске:

```bash
python parser.py --wait
```

В этом режиме скрипт соберёт всё, что доступно, а если результатов нет, будет раз в 5 минут проверять, не появились ли они, и сразу продолжит сбор. Если результаты пропадут посреди сбора (несколько страниц подряд не загрузились), скрипт снова перейдёт в ожидание. Работа закончится, когда будет собрано всё.

Перед тем как оставить компьютер на ночь:
- **отключите спящий режим** (Windows: Параметры → Система → Питание → «Переводить в спящий режим» → Никогда), иначе сбор остановится;
- не закрывайте и не сворачивайте окно Chrome;
- если ночью выскочит капча, скрипт будет ждать, пока вы её решите, — утром просто решите её и нажмите Enter.

Интервал проверки можно изменить в `parser.py` — параметр `WAIT_INTERVAL` (в секундах).

## Результат

**`results.csv`** в папке проекта — всегда. Файл сделан под русский Excel: разделитель `;`, дробные числа через запятую, кодировка UTF-8 с BOM. Он открывается в Excel двойным щелчком без «кракозябр».

**Google Таблица** — если указана в настройках. Числа записываются как числа, с ними сразу можно считать.

Формат колонок:

| Колонка | Пример |
|---|---|
| `ТИК`, `УИК`, `Ссылка на УИК` | `Алексеевская`, `УИК №101`, ссылка на страницу участка |
| `<отчёт> \| <колонка на сайте>` | `Явка Д1 \| 15:00 / Число`, `Явка Д1 \| 15:00 / %` |
| `Фед \| <строка протокола>` | `Фед \| Число избирателей, внесенных в список…` |
| `Одн \| <кандидат>` и `… (%)` | `Одн \| Иванов Иван Иванович`, `Одн \| Иванов Иван Иванович (%)` |
| `Фед \| Контроль протокола`, `Одн \| Контроль протокола` | `OK` или какое соотношение не сошлось |
| `Заявления (включены)` | число |
| `Заявления (исключены) \| По месту нахождения` / `\| ДЭГ` | число |

`Фед` — результаты по федеральному (партийному) списку, `Одн` — по одномандатному округу.

**Проценты за партии и кандидатов** скрипт считает сам, как ЦИК: от числа избирателей, принявших участие в голосовании (бюллетени в переносных + стационарных ящиках). Проценты явки берутся с сайта.

### Проверка протоколов

Сайт Избиркома защищается от автоматического сбора: таблица результатов приходит с сервера в перемешанном виде (например, `й6ч.з1яэ%` вместо `419`) вместе с инструкциями, по которым браузер собирает правильные числа на экране. В самой таблице на странице при этом остаются ячейки-приманки с неверными значениями.

Поэтому результаты скрипт берёт не с экрана: он перехватывает ответ сервера и сам выполняет эти инструкции — так получаются в точности те числа, которые видит человек. Если сайт изменит схему защиты и расшифровать ответ не получится, скрипт сообщит об этом и не запишет неверных данных.

Дополнительно каждый протокол проверяется по контрольным соотношениям:

- строка 2 = 3 + 4 + 5 + 6 + 11 − 12 (полученные бюллетени = выданные + погашенные + утраченные − не учтённые);
- 7 + 8 = 9 + 10 (бюллетени в ящиках = недействительные + действительные);
- строка 10 = сумма голосов за всех кандидатов (партии).

Если соотношения не сходятся, скрипт один раз перезагружает страницу. Если результат тот же — значит, так в самом протоколе на сайте (ошибки комиссий бывают). Тогда данные сохраняются, а в колонке «Контроль протокола» указывается, что именно не сошлось. Такие участки стоит проверить на сайте вручную.

## Остановка и продолжение сбора

- **Остановить:** нажмите `Ctrl+C` в терминале. Всё загруженное сохранится.
- **Продолжить:** просто запустите `python parser.py` снова. Скрипт пропустит уже собранное и продолжит с места остановки.
- **Начать заново** (например, если данные на сайте обновились):

  ```bash
  python parser.py --reset
  ```

Прогресс хранится в файле `parser_state.json`. Если какие-то страницы не загрузились даже после всех попыток, скрипт сообщит «Пропущено». В конце он сделает по ним повторные проходы, а при следующем запуске попробует их снова.

## Частые проблемы

**Сайт не открывается, `ERR_CONNECTION_RESET`, «Главная страница не загрузилась»**
Сайт Избиркома часто блокирует зарубежные IP-адреса. Проверьте, открывается ли `start_url` в вашем обычном браузере. Если нет — нужен российский IP-адрес (например, VPN с российским сервером). Также сайт иногда просто перегружен: скрипт сам делает паузы и повторы, но при массовых ошибках имеет смысл остановить его и попробовать позже.

**«Не удалось найти ТИКи автоматически»**
Скорее всего, на сайте ещё (или уже) не опубликован отчёт о явке по вашему округу — проверьте вручную. Если отчёт есть, а скрипт его не видит, впишите ТИКи вручную в `config.json`. Ссылки на них можно взять из дерева комиссий на сайте:

```json
"tik_urls": {
  "Алексеевская": "http://izbirkom.ru/election/587813923/commission/b289fb16-8520-4392-bff8-d05684a5fe33/",
  "Большеглушицкая": "http://izbirkom.ru/election/587813923/commission/..."
}
```

Если до этого был неудачный запуск, добавьте флаг `--reset`.

**Страницы долго грузятся / «Таблица не загрузилась (попытка N/5)»**
Нормально, если это случается изредка: сайт иногда отдаёт страницы не с первого раза, и скрипт повторит попытку сам. Если такое происходит на всех страницах подряд, проверьте, открываются ли отчёты в обычном браузере — возможно, данные ещё не опубликованы.

**`This version of ChromeDriver only supports Chrome version …`**
Версии Chrome и драйвера не совпали. Узнайте версию Chrome (меню ⋮ → Справка → О браузере Google Chrome, первое число, например `128`) и впишите её в `config.json`: `"chrome_version": 128`.

**`ModuleNotFoundError: No module named 'distutils'`**
Бывает на Python 3.12+. Выполните `pip install setuptools`.

**`Не найден config.json`**
Вы не создали файл настроек — см. [шаг 3](#3-файл-настроек-configjson).

**`Не найден credentials.json`, хотя файл лежит в папке**
Windows скрывает расширения файлов, и файл на самом деле называется `credentials.json.json`. Включите показ расширений (Проводник → Вид → Показать → Расширения имён файлов) и переименуйте. То же относится к `config.json`.

**«Таблица не найдена»**
Проверьте ссылку в `google_sheet_url` и то, что email сервисного аккаунта добавлен в доступ к таблице с правами **Редактор**.

**«Ошибка в config.json»**
Нарушен формат JSON. Частые причины: пропущена запятая между строками, лишняя запятая после последней строки, «кавычки-ёлочки» вместо обычных `"`.

**«Не удалось обновить results.csv»**
Файл открыт в Excel, и Windows не даёт его перезаписать. Закройте его — данные запишутся при следующем сохранении.

## Для продвинутых: другие выборы и отчёты

Адреса отчётов задаются в начале `parser.py`, в блоке **«РАСШИРЕННЫЕ НАСТРОЙКИ»**:

```python
TIK_REPORTS = {             # отчёты, где УИКи идут строками таблицы ТИКа
    "Явка Д1": "voting-flow?type=2&report=453",
    ...
}
UIK_REPORTS = {             # отчёты, которые открываются для каждого УИКа
    "Фед": "results?type=6&report=242",
    ...
}
```

Ключ (`"Явка Д1"`) — это префикс названий колонок, значение — окончание адреса страницы отчёта. Номера `type` и `report` могут отличаться в других выборах: откройте нужный отчёт на сайте вручную и посмотрите окончание ссылки в адресной строке. Например, если выборы однодневные, лишние дни явки можно просто удалить из `TIK_REPORTS`.

Там же настраиваются:

- `SHORT_NAMES` — сокращения для слишком длинных заголовков колонок;
- `DROP_COLUMNS` — колонки, которые не нужно сохранять;
- `PAGE_TIMEOUT`, `MAX_ATTEMPTS`, `RETRY_PASSES` — ожидание и число повторов при загрузке страниц;
- `PAUSE_RANGE` — случайная пауза между страницами. Не делайте её слишком маленькой: это и повышает риск капчи, и лишний раз нагружает сайт;
- `CSV_DELIMITER` — разделитель в CSV (`";"` для русского Excel, `","` для остальных программ).
